# Permanent main-card illustration standard

Applies to all expansions, not spritesheets, units, boosters or banners.

Measured shared FeatureCard windows: short rules16:10; medium (>100 characters)16:9; long (>150)2:1. Catalog and enlarged preview reuse this component. Mundo Gélido is2:1. Hand CardView instead has a responsive fixed-height art band: review in actual combat separately; do not pretend it has one invariant ratio.

Generate/edit landscape16:9, request2048×1152+. Verify actual output; the tool currently returns approximately1672×941. Preserve native masters; deliver1600×900 JPEG88 without upscaling. Tiny native aspect rounding is acceptable, portrait stretching is not.

Keep critical face/hands/action inside central75%width/80%height. Fill sides naturally with scene, not blur or duplicated subjects. No text, UI, border, cost or logos. Good existing portraits require reference-guided lateral expansion, not needless regeneration. Save originals and versioned edits; inspect identity, anatomy and action. Generative expansion is not guaranteed pixel-identical preservation.

Do not resize the UI window to conceal an asset mistake. Only approved horizontal resources receive data-landscape-art and may use modest safe responsive crops to16:10/2:1 with no blurred backdrop. Never use that treatment on portrait resources. Check head/hands/essential action after cropping. No aggressive cropping.
